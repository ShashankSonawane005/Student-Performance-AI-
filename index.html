-- one consolidated row per student
CREATE VIEW v_student_performance AS
SELECT s.student_id, s.name, s.attendance_pct, s.study_hours,
       COUNT(m.mark_id) AS subjects, ROUND(AVG(m.internal_marks),2) AS avg_internal,
       ROUND(AVG(m.total),2) AS avg_total
FROM students s LEFT JOIN marks m ON m.student_id = s.student_id
GROUP BY s.student_id;

How the AI works

No external libraries. The model learns from whatever is in the database.

ReadQuery the view for attendance, study hours and average internal marks.
BuildDesign matrix [1, attendance, hours, avg internal] for every student.
SolveRidge normal equations (λ = 1) solved with Gauss-Jordan elimination.
PredictScore is clipped to 0–100, then mapped to a risk level.
StoreResults are saved to the predictions table and shown in the JOIN report.
